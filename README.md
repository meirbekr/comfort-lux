# Comfort Lux — Премиальная Мебель & Дизайн Интерьера

Современный веб-сайт (лендинг) для ателье премиальной мебели **Comfort Lux** с встроенной административной панелью управления контентом, динамическим каталогом товаров и возможностью загрузки медиафайлов.

---

## 🚀 Быстрый ручной запуск (Локально)

### Требования
- **Python 3.10+** (Рекомендуется Python 3.11 или 3.12)
- **Git**

---

### Шаг 1. Клонирование репозитория
Откройте терминал (PowerShell или Git Bash) и выполните:
```bash
git clone <ссылка_на_ваш_репозиторий>
cd mebel
```

---

### Шаг 2. Создание и активация виртуального окружения (`venv`)

#### На Windows (PowerShell):
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```
*(Если в PowerShell появляется ошибка выполнения скриптов, выполните `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`)*

#### На Linux / macOS:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

---

### Шаг 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

---

### Шаг 4. Настройка логина и пароля администратора (`.env`)
Создайте файл `.env` в корневой папке проекта (или отредактируйте имеющийся):
```env
ADMIN_USER=admin
ADMIN_PASS=admin123
SECRET_KEY=comfort-lux-secret-key-2026
```
> *Вы можете указать любой свой логин и пароль.*

---

### Шаг 5. Запуск сервера

#### Вариант А. Через Uvicorn:
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8080 --reload
```

#### Вариант Б. Через Makefile (если установлен `make`):
```bash
make run
```

---

### 🌐 Адреса в браузере после запуска:
- **Главная страница сайта**: `http://localhost:8080/`
- **Панель администратора**: `http://localhost:8080/admin`

---

## 🐳 Запуск через Docker

 Если у вас установлен Docker, запустить проект можно в контейнере:

```bash
# 1. Сборка Docker-образа
docker build -t comfort-lux .

# 2. Запуск контейнера на порту 8080
docker run -d -p 8080:8080 \
  -e ADMIN_USER=admin \
  -e ADMIN_PASS=admin123 \
  --name comfort-lux comfort-lux
```

Для остановки контейнера:
```bash
docker stop comfort-lux && docker rm comfort-lux
```

---

## 🛠️ Функционал административной панели (`/admin`)

При переходе по адресу `http://localhost:8080/admin` откроется панель управления:

1. **Авторизация**: Вход по логину и паролю из файла `.env`.
2. **Вкладка «📝 Тексты и Ссылки»**:
   - Изменение телефона, WhatsApp, Instagram, часов работы, описания студии и текстов кнопок.
   - Рядом с полями медиа есть кнопка **«📁 Загрузить»** для выбора файлов с компьютера.
3. **Вкладка «🛋️ Управление Каталогом»**:
   - **Добавление товаров**: Кнопка **«+ Добавить новый товар»**.
   - **Редактирование/Удаление**: Изменение названия, цены, категории, бейджа и загрузка фото.
   - **Сохранение**: Нажмите **«Сохранить изменения»** для применения новых данных на сайте.

## 📁 Структура проекта

```text
mebel/
├── app/
│   ├── __init__.py
│   ├── auth.py         # Логика авторизации, сессий и cookie
│   └── main.py         # Точка входа FastAPI, API эндпоинты
├── assets/             # Изображения, логотип, иконки
│   └── uploads/        # Папка для загруженных через админку медиафайлов
├── index.html          # Главная страница (лендинг)
├── app.js              # Интерактивная логика фронтенда и загрузка JSON
├── styles.css          # CSS стили
├── admin.html          # Интерфейс админ-панели
├── admin.js            # Управление админкой и загрузка файлов
├── content.json        # Файл хранения редактируемого контента и каталога
├── requirements.txt    # Зависимости Python
├── Dockerfile          # Docker-контейнеризация
├── Makefile            # Команды для быстрого запуска
└── .env                # Переменные окружения (логин/пароль админа)
```
